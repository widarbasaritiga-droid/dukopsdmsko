STRUKTUR DATA LOKAL DUKOPS
==========================

Daftar file desa:
  data/desa/daftar.txt

`daftar.txt` berisi satu nama file `.txt` desa per baris.
Nama desa pada pilihan dibuat otomatis dari nama file.
Isi setiap file desa adalah koordinat, satu koordinat per baris.

Contoh:
Sukasada.txt
